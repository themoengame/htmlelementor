Cara Impor ZIP Kit ke Elementor

  1. Download file .zip hasil ekspor
  2. Masuk ke WordPress Dashboard → Elementor → Tools
  3. Pilih tab Import/Export Kit → klik Start Import
  4. Upload file .zip, lalu pilih Templates & Content
  5. Template siap digunakan di Elementor → My Templates
  6. Tips: Gambar otomatis terupload ke Media Library!
