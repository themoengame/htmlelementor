Cara Impor ke Elementor

  1. Download file .json hasil ekspor
  2. Masuk ke WordPress Dashboard → Templates → Saved Templates
  3. Klik Import Templates dan unggah file .json
  4. Buka halaman Elementor, klik folder → My Templates, lalu sisipkan template
  5. Tips: Semua widget dapat diedit seperti biasa!
